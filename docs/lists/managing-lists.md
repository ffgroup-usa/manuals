## Managing License Plate Lists

CAMMRA AI offers the functionality to add license plates to both the Block list and Allow list. You can conveniently add license plates directly through the web interface or import them from a CSV file. Here's how to manage the lists:

Access the CAMMRA AI application's web page.

Navigate to the appropriate section or tab for managing license plate lists (LISTS).

To add a license plate to the list, enter the license plate number directly or use a license plate pattern with wildcards.

For example, to add license plates starting with "SL" followed by any three characters to block list, use the pattern "SL???". The question mark represents any single character.

Similarly, use an asterisk (*) to represent any number of characters in a license plate. For instance, to add license plates starting with "M" followed by any number of characters to block list, use the pattern "M*".

Optionally, provide a description for each listed license plate for reference purposes.
